# Kost Check

Website checklist perlengkapan untuk membantu persiapan pindah ke kos pertama kali.

## Menjalankan

Buka `index.html` di browser. Tidak ada dependensi atau proses build.

## Catatan mode demo

Login saat ini hanya simulasi antarmuka. Email dan progres checklist disimpan di
`localStorage` browser; kata sandi tidak disimpan maupun diverifikasi. Ini cocok
untuk demo lokal, bukan autentikasi produksi. Untuk penggunaan nyata, hubungkan
form login ke layanan backend yang aman.
